# Daily Task Mover

将当前每日笔记或 Journals 条目中顶部任务（含所有富文本子项）移动到上一周期或下一周期的笔记，并按源笔记中任务所在标题自动归位。

## 功能

- 通过每条顶部任务行尾的行内图标移动任务，或通过命令面板触发
- 可自定义左键 / 右键点击动作：弹出菜单、移动到上一周期、移动到下一周期、无动作
- 任务整体移动：含子项（嵌套列表、图片嵌入、引用等）的任务块一同移动
- 标题归位：追加到目标笔记中同名同级标题段末尾；目标无该标题时自动新建
- 冲突检测：目标笔记已包含相同任务行时弹 Notice 提示，不移动
- 格式兼容：支持 Daily Notes 插件配置的任意 moment.js 日期格式（如 `YYYY-MM-DD`、`YYYY.MM.DD`、`YYYY/MM/DD`、嵌套 `YYYY/YYYY-MM/YYYY-MM-DD` 等）

## 前置要求

- 启用内置「每日笔记」（Daily Notes）核心插件，或 [Journals 社区插件](https://github.com/srg-kostyrko/obsidian-journal)（3.0 或更高版本）。
- 使用 Daily Notes 时，本插件根据其日期格式、文件夹和模板配置识别并创建笔记。
- 使用 Journals 时，请打开 journal 条目。任务会移动到同一个 journal，目标笔记的位置、模板和创建提示由 Journals 处理；支持每日、每周、每月、每季度、每年和自定义周期。移动时使用当前周期开始前一天或结束后一天的日期，由 Journals 确定相邻周期。
- 「笔记提供插件」默认为「自动」：优先使用 API 可用的 Journals，否则使用 Daily Notes。整个仓库只使用一个插件，不会根据当前笔记切换。也可手动选择 Daily Notes 或 Journals。使用 Journals 时可以关闭 Daily Notes 核心插件。

Daily Notes 每次移动一天；Journals 每次移动到同一个 journal 的相邻周期。

## 使用方法

1. 打开每日笔记或 Journals 条目
2. 将鼠标悬停在顶部任务上——行尾会出现箭头图标
3. 左键（或右键，取决于你的设置）点击图标，将任务移动到上一周期或下一周期；或通过命令面板执行对应命令

## 设置

- **笔记提供插件**：选择「自动」（默认）、`Daily / Periodic notes` 或 `Journals`。下拉列表会区分“不可用”（未安装）、“已禁用”和“版本不受支持”；只有已启用且兼容的插件可以选择。已保存的插件选择失效时，会保留选择并停止移动任务；重新启用插件或选择“自动”即可恢复。手动选择不会回退到其他插件。

- **左键点击动作 / 右键点击动作**：选择点击行内图标时执行的动作——`弹出菜单`、`移动到上一周期`、`移动到下一周期`、`无动作`
- **启用上一周期 / 启用下一周期**：控制弹出菜单中是否显示对应选项。仅当左键或右键点击动作为`弹出菜单`时才可修改
