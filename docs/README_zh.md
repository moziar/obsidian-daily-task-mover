# Daily Task Mover

将当前日记笔记中顶部任务（含所有富文本子项）移动到前一天或后一天的日记笔记，并按源笔记中任务所在标题自动归位。

## 功能

- 通过每条顶部任务行尾的行内图标移动任务，或通过命令面板触发
- 可自定义左键 / 右键点击动作：弹出菜单、移动到前一天、移动到后一天、无动作
- 任务整体移动：含子项（嵌套列表、图片嵌入、引用等）的任务块一同移动
- 标题归位：追加到目标笔记中同名同级标题段末尾；目标无该标题时自动新建
- 冲突检测：目标笔记已包含相同任务行时弹 Notice 提示，不移动
- 格式兼容：支持 Daily Notes 插件配置的任意 moment.js 日期格式（如 `YYYY-MM-DD`、`YYYY.MM.DD`、`YYYY/MM/DD`、嵌套 `YYYY/YYYY-MM/YYYY-MM-DD` 等）

## 前置要求

- **Obsidian 内置「每日笔记」（Daily Notes）核心插件必须启用**：本插件依赖其配置（日期格式、文件夹、模板）来识别和定位日记笔记。请在「设置 → 核心插件」中确认「每日笔记」已开启。

## 使用方法

1. 打开任意日记笔记
2. 将鼠标悬停在顶部任务上——行尾会出现箭头图标
3. 左键（或右键，取决于你的设置）点击图标，将任务移动到前一天或后一天；或通过命令面板执行对应命令

在编辑模式中选择多个任务行，然后执行移动命令或点击选区内的移动图标。选择父任务时会包含其全部子项，重叠选中的任务只移动一次。如果任一任务与目标笔记冲突，整批移动都会在写入前停止。

## 设置

- **左键点击动作 / 右键点击动作**：选择点击行内图标时执行的动作——`弹出菜单`、`移动到前一天`、`移动到后一天`、`无动作`
- **启用前一天 / 启用后一天**：控制弹出菜单中是否显示对应选项。仅当左键或右键点击动作为`弹出菜单`时才可修改
